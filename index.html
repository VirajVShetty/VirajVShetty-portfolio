Fairness auditing

sliceguard

A fairness slice auditor with Wilson and Newcombe intervals on every slice, Benjamini-Hochberg correction across all slices tested, and a minimum detectable effect. Underpowered slices are marked INDETERMINATE.

  • Ranks by the lower bound of the gap interval instead of the raw point estimate
  • Demo audits 6,000 synthetic underwriting-model evaluations with two planted 9-point disparities
  • Python
  • Statistics
  • Wilson intervals

Source on GitHub

Time-series validation

purgedcv

Purged, embargoed walk-forward cross-validation for time series, plus a harness that measures how much of a backtest's reported skill is leakage. It scores one model under four protocols on synthetic data where the true skill is known, including a zero-signal control.

  • On a zero-signal series, naive k-fold overstated accuracy by 8.35 percentage points
  • The label horizon is mandatory, so overlap leakage cannot be reintroduced by default
  • Python
  • Time series
  • Statistics

Source on GitHub

Data integrity

tamperlog

A hash-chained audit log with Merkle checkpoints whose roots sit in a separate witness store. It catches re-chained truncation and edits that plain hash chaining accepts.

  • On a 20,000-entry log with a checkpoint every 1,000 entries, chain-only checks missed 3 of 7 tamper classes; with checkpoints all 7 were detected
  • Inclusion proofs for any entry, with domain-separated leaf and node hashes
  • Python
  • Merkle trees
  • SHA-256
